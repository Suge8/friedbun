# 视频布局

视频是一眼看懂整帧，不是仔细阅读密集 UI。目标：画面停留不到一秒也能读懂。

## 构图

- 每个场景定一个观众最先注意的焦点，围绕它构图；可读元素不与主运动物体争同一区域。
- 安全区：1080 宽的视频，关键文本离左右至少 80px、离上下至少 100px；字幕底部边距 ≥5%，不压在运动路径上。
- 用居中、堆叠或强对齐的布局，不用分散的仪表板式布局；留白有意为之。
- 两个元素互相竞争时，依次展示或把其中一个明确放到次要位置，不因为有空间就并排。
- 宣传片、讲解和动态图形的默认场景：一条主信息 + 一个支撑视觉（图标、产品卡、形状或截图式模型）+ 一两个背景强调。许多卡片、徽章、边框、胶囊和小标签是 Web UI 模式，会让视频显得杂乱。

## 用布局防止重叠

- 可读内容（标题、标签、字幕、数据）放在 `flex`/`grid` 容器里，用 `gap`、`justifyContent`、`alignItems` 排布；不用各自独立的 `top`/`left`/`right`/`bottom` 手动定位。
- 绝对定位只给背景、装饰形状、发光、粒子等垫在内容后面的层。
- 为场景中每个主要元素预留一个槽位，例如竖版促销场景用带 `gap` 的居中列放标题、卡片、CTA。
- 用 `opacity`、`transform`、`scale` 在槽位内做动画，不动到别的元素占的空间；从屏幕外进入的元素，最终静止位置也属于它的槽位。
- 文本长度未知或由用户提供时按会换行设计，给足宽高，正下方不紧贴别的对象。

## 视频中的文字

- 1080 宽合成的最小字号：主标题 84px、重要支撑文字 44px、标签或短标注 32px；按合成宽度等比放大（1920 宽主标题 ≥150px）。拿不准就放大。
- 小字视为装饰，除非用户明确要观众读它。
- 行短；长想法拆成多个场景，不缩字号。
- 文字与背景强对比；难读时加一块淡背景形状或简化背景。
- 同一区域不堆多块文字，每条信息给自己的时刻或明确分隔的区域。

## 用时间解决拥挤

- 功能一个接一个展示，不一次全上。
- 画面拥挤时删一个元素、放大焦点，或把次要元素移到另一个场景。
- 背景形状、渐变和卡片只用来支撑信息。
- 跨场景保持一致的视觉系统：重复的间距、对齐和一小组形状与颜色。
