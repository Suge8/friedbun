# 排版

修改用项目已有的样式体系表达（Tailwind 项目写 utility），不为排版修复引入第二种写法。审查时读页面而不是扫代码：眯眼看层级，完整读一段，拉伸视口看真实长度下的换行与截断。

## 字体

- 沿用项目已有字族；只有任务明确要求换字体时才换，不为通过审查引入付费或专有字体。
- 字体通常不超过三种。配对求对比而非相似：衬线标题配无衬线正文像刻意的展示/阅读分工，两种近似的无衬线像失误。
- 名字带 Display 不等于展示字体：SF Pro、Heldane 等分 `Display`（大字号）和 `Text`（小字号）两个变体，按字号选用。
- 细字重只给展示字：18px 以下至少 400；100–300 只用于 28px 以上，且要看在背景上是否站得住。
- 中文界面字重只用常规 400 与强调 700 两档：Windows 上的微软雅黑只有这两档，500 会回落成常规，在 Mac 上成立的层级到 Windows 就消失。
- 用属性而非原始标签：`font-weight: 650` 而非 `font-variation-settings: "wght" 650`，`font-variant-numeric: tabular-nums` 而非 `"tnum" 1`；回落到非可变字体时属性仍生效。原始标签只留给没有属性的自定义轴（`"GRAD" 80`）和小众特性（`"ss01" 1`）。
- 加载设计实际用到的字重与字形，避免浏览器合成粗体斜体。`font-synthesis: none` 会同时关掉粗体、斜体、小型大写、上下标合成，只在验证过整条回落链的独立处理（如品牌字标）上用；只想关一种时用对应长写属性。

## 字阶

产品界面按角色定字阶，每个角色一次决定字号、行高、字重：

| 角色 | 字号 | 行高 | 字重 |
|---|---|---|---|
| Display | 2.25rem（36px） | 1.1 | 600 |
| Title | 1.5rem（24px） | 1.2 | 600 |
| Heading | 1.125rem（18px） | 1.3 | 600 |
| Body | 1rem（16px） | 1.5 | 400 |
| Caption | 0.8125rem（13px） | 1.4 | 400 |

- 角色内强调升一档字重（400 → 500），不改字号。
- 标题级别映射到递减的字阶档；审查时比较同一语义区块内标题的计算字号，子标题不压过父标题。深层级可以共用字号，靠字重或字距区分。标题不比正文小，刻意的 label 式 overline 除外。不按浏览器默认字号挑标题元素。
- 团队项目按用途给字号命名（`text-body-sm`），不按大小命名。

## 行高与字距

- 标题约 1.1，正文 1.5–1.6，用无单位值。会换到 3 行及以上的文字至少 1.4，即使在列表行、卡片这种高度受限处：行距挤的段落比高一点的行更难读。
- 大标题略负字距（`-0.02em`）；小号大写标签略正字距（`0.05em`）；正文都不需要。
- 按钮、徽标里文字看起来偏下时用 `text-box` 裁掉字体自带的上下留白：`text-box: trim-both cap alphabetic`。不支持的浏览器只是不裁切，按渐进增强用。

## 换行与截断

- 长文行长约 60–75 字符；16px 正文约 560–680px，即 Tailwind `max-w-xl`（576px）或 `max-w-2xl`（672px）。正文字号变了就重算。
- `text-wrap: balance` 只用于标题，`pretty` 用于描述；长文两者都不用（浏览器对多行 `balance` 本就忽略，均衡整段浪费空间）。
- 长单词、链接、ID 可能撑破容器处用 `overflow-wrap: break-word`；标签与徽标用 `white-space: nowrap`。界面里不两端对齐。
- 单行截断 `text-overflow: ellipsis` 需配 `overflow: hidden` 和 `white-space: nowrap`；多行用 `line-clamp`。截断的内容重要时，在 tooltip 或展开视图里给出全文。
- 要动画的下划线（不只是换色）做成独立元素：真实 `text-decoration` 只有颜色能可靠过渡。静态下划线用 `text-underline-offset`、`text-decoration-skip-ink: auto` 或 `from-font` 度量。
- 文案按自然大小写存储，大写用 `text-transform`。值与单位之间用 `&nbsp;` 不断开（`16&nbsp;px`）。

## 混合方向

- 在方向变化的边界设 `lang` 和 `dir`；空间镜像用逻辑属性（`margin-inline-start` 等）。
- 一两行的片段跟随界面方向；三行以上的段落按自身语言方向对齐，RTL 界面里的英文段落仍然左起（`text-align: start` 加正确的 `lang`/`dir`）。
- 数字在任何方向都保持原顺序；相邻 RTL 文字打乱数字或混排值时用 `<bdi>` 隔离。

## 选中

- 默认保持文字可选，包括应用外壳上的标签、标识和错误信息。`user-select: none` 只用于拖拽或手势表面这类误选确实干扰交互的地方，以及手机上的控件（见 `mobile.md`）。
- `::selection` 可以带品牌色的低饱和版本，选中文字仍可读。
