# 图表与 KPI

- 标题写指标名（「月收入」），不带图表类型。数据固定的报告图可以用结论当标题（「3 月以来收入翻倍」）；实时数据的结论会过期，用中性标题。
- 读图说明（「每根柱代表一个月」「悬停查看详情」）不写。
- 一个数值只编码一次：坐标轴和网格线给形状，印出的数值只给要紧的点（末点或最大值）。KPI 留数值、一个方向提示和对比周期（「▲ 12% 较上月」），不再叠「上升」字样和一句复述。
- 数据最显眼，标签其次，网格线和坐标轴最淡：网格线留几条浅灰发丝线和一条基线；绘图区的边框与底色、次刻度、粗轴线、3D、数据图形上的阴影与光晕都去掉。
- 四条及以内的序列把名称直接标在线尾或柱旁，可带最新值（「今年 1,150」），不用图例；序列更多或图形挤到标不下时才用图例。单序列不出图例。
