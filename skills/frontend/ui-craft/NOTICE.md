# 来源与许可

ui-craft 的部分规则吸收自下列 MIT 项目，保留版权声明；agent 不需要读本文件。

- [emilkowalski/skills](https://github.com/emilkowalski/skills)（Copyright (c) 2026 Emil Kowalski）：emil-design-eng、animate、review-animations、mobile-native。用于 `reference/motion.md`（工具阶梯、`scale(0)` 禁令、Base UI 属性、clip-path 配方、长按确认、手风琴、滚动揭示、装饰性 spring、慢放检查）、`reference/gestures.md`（触屏轴向；Sonner/Vaul 的速度阈值 dismiss 与多点保护）、`reference/mobile.md`、`reference/forms-and-feedback.md`（标签页隐藏时暂停 Toast）。
- [jakubkrehel/skills](https://github.com/jakubkrehel/skills)（commit a6733339）：better-accessibility、better-colors、better-typography、icons。用于 `reference/accessibility.md`、`color.md`、`typography.md`、`icons.md`。

`reference/gestures.md` 的动量投射与 rubber-band 公式、`reference/motion.md` 的 damping/response 对照来自 Apple WWDC 2018 *Designing Fluid Interfaces*。
