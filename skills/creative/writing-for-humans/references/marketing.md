# 营销页

- 功能连到用户得到的结果。
- 每个区段只推进一个论点，区段顺序构成说服链；Hero 后逐个功能平铺的页面是清单，不是论证。
- CTA 写「动作 + 获得物」，不写 Submit、Learn More、「了解更多」。
- 客户评价写出具体结果，不用「Great product!」「Love it!」式空夸。

| 页面 | 重点 |
| --- | --- |
| 首页 | 先讲最广泛的核心价值，再给不同意图清晰入口 |
| 落地页 | 一个主张、一个主 CTA，标题与流量来源一致 |
| 定价页 | 帮用户选套餐：差异、适用对象、购买顾虑 |
| 功能页 | 功能 → 收益 → 结果，并给出试用路径 |
| 产品描述 | 先说用途和差异，再补规格与限制 |

成稿按页面区段组织；标题和 CTA 各给 2–3 个候选。
