# 导演流程

把主题做成运动优先、像视频不像幻灯片的成片。按步骤走，每步达到完成标准再进下一步。第 2、4 步的选择：用户在场交给用户挑，全自动时自选并写一句理由。

## 1. 接收

先定片型和时长：它们决定字数、能讲几点和节奏。再只问会改变制作路线的缺口：受众与平台、比例、旁白/无声/带字幕、事实准确级别、指定风格、参考视频或素材、配乐来源。用户只给主题就按最佳判断直接做；比例未指定时按平台定（抖音、小红书、视频号、Reels、Shorts 用 9:16，其余 16:9），默认带旁白。

| 片型 | `format` | 用于 | 时长 | 讲几点 |
|---|---|---|---|---|
| 短视频 | `short` | 宣传、发布、社交平台 | 15–35 秒 | 一个核心主张加一条证据，30 秒最多两点 |
| 解说 | `explainer` | 科普、历史、原理、教程 | 30–90 秒 | 每 10–15 秒一个要点 |

片型写进 `timeline.json` 的 `format`，语速、停顿、静止、换镜、主体大小这组参数跟着取模板 `src/formats.json` 里的那一组（含义见 `src/timeline.ts`）；两种片型的写法和节奏差别在第 3 步。全片字数先按 实测语速 ×（时长 − 停顿总和 − `tail`）估，合成后看 `fish_tts.py` 输出的 `duration`，差多少就增删句子，重合成只要几秒。单句量出的语速通常比整篇合成快一成，估字数时乘 0.9。用户要讲的内容超出时长装得下的，先说清代价（延长到多少秒，或砍掉哪一点）让用户选，不硬塞；内容讲完比目标短几秒时就让它短，不为凑时长加卖点。

事实性主题（历史、科学、法律、医疗、金融、时事、具名实体）先核实核心主张，日期写绝对日期。屏上的数字、引语、评价只来自用户材料或已核实来源（计数器的中间值不算，起点和终点要有出处）；示意数据用相对条形或骨架线，交付时列出哪些是示意。

给了参考视频：`python3 <skill 目录>/template/scripts/media.py check <参考.mp4>` 量出静止占比、硬切和镜头时长，再看一张抽帧图里最大元素占画面多少。只取节奏数字和"每个物体都遵守的那一条造型规则"，不抄节拍顺序和画面。

路线按第 5 步的表在这一步定下；A、B 把 skill 的 `template/` 复制成项目目录（见 [Remotion](remotion.md)）。模板是竖版短视频：横版把 `timeline.json` 的宽高改成 1920×1080，解说片把 `format` 改成 `explainer`；之后的文件都放在项目根。

完成：片型、时长、路线、比例、配乐来源已定；事实主张已核实或标为示意，出处写进项目根的 `DIRECTION.md`。

## 2. 方向

先写一句：同类题材的视频通常长什么样（常见开场、隐喻、版式），点出其中让它们平庸的做法（整段录屏连播、三张功能卡轮播、打字机敲命令），那是要避开的；题材本身要看的东西（产品界面、实物、人）照样当主角。再写方向，每个是一句运动论题；解说片写 2–3 个，短视频只有一个主张时写一个即可：

`这部视频通过展示 <画面主体> 从 <起始状态> 变成 <结束状态>，来证明 <核心主张>。`

- 写了几个方向时，它们的画面主体、结构和招牌镜头要不同，否则合并成一个。每个方向写一句招牌手法（全片只在 1–2 拍出现的画面），和一个具名参考（导演、片子、印刷流派）；"高级""现代""电影感"这类形容词不算参考。
- 换掉标题后还能套到别的主题上，说明方向太泛，重写。
- 画面上每个东西，观众不听旁白也叫得出是什么：真实物件、真实界面，或一眼认得出的符号（钥匙、放大镜、勾）。自造的抽象符号（一根线代表指令、一块玻璃代表模型）观众解不开，不当主角；带坐标和标注的示意图可以用，但和它说明的那个实物（机翼、气流）同框出现。软件、服务这类看不见的能力，宣传片用生成插图里的角色和实物演出来（拿放大镜挑错的审查员、被退回的卷宗、盖下的通过章），真实界面只在一两镜里作佐证；整片靠截图卡片撑，读作幻灯片。教人怎么操作的演示片例外，全程用真实界面。

叙事弧按内容选一条：

| 弧 | 适用 | 节拍形状 |
|---|---|---|
| hook_payoff | 单一想法，默认 | 钩子 → 背景 → 推进 → 兑现 → 收尾 |
| timeline | 历史、演化、旅程 | 起点 → 事件 → 转折 → 现在 → 收束 |
| how_it_works | 产品、流程 | 钩子 → 是什么 → 2–3 个步骤 → 收益 → CTA |
| pas | 痛点广告 | 问题 → 加剧 → 解决 → 证据 → CTA |
| bab | "之后"比痛点好卖 | 之前 → 之后 → 桥梁 → CTA |

完成：方向、被否掉的第一反应和替代它的手法写进 `DIRECTION.md`。

## 3. 时间表

全片时间只存在项目根的 `timeline.json`：画面、字幕、声音和检查脚本都读它。

### 文稿

先挑好音色、按片型的 `speed` 合成一句量出语速（见 [声音](sound.md)），定字数，再写旁白文稿：

- 短视频：第一句和第 0 帧给同一个冲突或问题（出错的那个结果、反常的画面、最意外的数字），答案留到兑现拍，标题不写结论，不铺垫痛点；之后每句推进一步：是什么 → 证据（数字、对比、真实画面）→ 行动。宣传片卖的是用了之后用户的处境变成什么样（"你去睡觉，醒来拿到的是修好的代码"），机制只在一拍里当证据，不从机制讲起。一句话说不出的卖点，不放进这支片子。核心卖点要有一个演示镜头："输入 → 结果"放大到画面四成以上、停 1.5 秒；只用文字说出来的卖点不算演示。宣传片的产品在前 3 秒出场，身份是来解决问题的那一方，不和问题画在一起让人读成它造成了问题；最后 3–5 秒给行动（名字、装法、链接），单独一屏、停 1.5 秒以上，行动那一行是全屏最大的可读字，屏上只留产品名、一句好处和它。科普短片结尾落在兑现的那个事实上。
- 解说：讲一个有人、有难处、有转折的故事；概念题也找一个具体的人或物去经历它，比如一个数据包、一位工程师。
- 口语短句，一句只说一件事；数字和名词说具体的，不用"许多""巨大"带过。
- 不写对仗和排比金句，不写"从此……""这一刻……""不仅……更……"，不用反问开头，不用"见证""璀璨""传奇"这类空词，结尾不总结、不升华，落在一个具体的画面或事实上。
- 古文原文不直接念，先转成白话；必须引原文时，原文上屏，旁白念白话。
- 宣传片定稿前先写 5 个候选钩子（第一句加第 0 帧画面），交给第 4 步那样的陌生人测试，问它看完想不想用、为什么，选它最想用的那个。
- 写完按旁白的语速默读一遍，第一次听就听不懂的句子重写。用户在场时，先把文稿给用户看过再合成。

### 旁白先行与锚点

把定稿的旁白逐句写进 `lines`，节拍在 beats 里写从哪句开始（`from`），兑现那一拍标 `"payoff": true`，然后跑 `python3 scripts/fish_tts.py --timeline timeline.json`：它生成音频，写回每句和每拍的实际起止与总时长。再按它排画面，不先写死时长再塞声音。要卡在某个词上，就在那个词前断句。

音效、配乐关键帧和组件里的出现时刻都写成锚点（如 `"l3+0.2"`，写法见模板 `src/timeline.ts`），旁白重生成后跟着走，只有动画自身的时长写成常量。画面动作和音效都要卡的时刻（印章落下、门关上）起名写进 `marks`，两边引用同一个名字。

### 节拍表

每拍演什么写在 `DIRECTION.md` 的节拍表里，按 beat 的 id 一拍一行，画面改了就同步改。每拍两项：

- `show`：这拍旁白说的那件事由画面上哪个物体做什么变化演出来（起始态 → 结束态）。关键转折里"谁做了什么"要有看得见的动作，不能只靠旁白说；核心对比遮住字幕也要看得出谁赢、差多少（同一时刻一边还炸毛、一边已躺平）。
- `carry`：本拍与下一拍边界上存活并继续运动或缩放的元素，例如光标、主体、变成下一场景的容器、贯穿全片的一条线；不必是下一拍才揭晓的东西，不要为了承接提前露出答案。切镜（换景别、换机位）随时可用，同一主体跨过切点保持位置或运动方向就算承接；写不出 carry 就写"硬切"，要避免的是把整个世界换掉。

### 排时间

- 元素在旁白说到它时出现（关键词前约 0.15 秒），不在一拍开头一次摆满。
- 第 0 帧是封面：主体加一句标题的完整画面，平台缩略图和静音自动播放都取它；这一拍的其余元素仍随旁白出现。短视频的封面是全片冲突或反差最强的那一刻，不是静止的物件配一句口号。
- 钩子约 3 秒：第一句旁白 2–3 秒说完（字数约为实测语速 × 2.5），钩子标题约 6 字，可以停进下一拍读完（第一句 `gap` 设 0.2）。
- 短视频第 1 秒内就有明显动作或一次切镜，前 3 秒至少两次画面变化；之后每 1.5–3 秒换一次构图（切镜、换景别或明显的推拉移，同一机位里贴图平移不算），不超过 `shot` 秒。解说片单镜不超过 `shot` 秒，一句旁白长过它就配两镜（带标题的广角 + 无标题特写），旁白跨镜连续；必须同屏的对比和读字的停留可以更长，审片时写明理由。
- 整帧静止不超过 `still` 秒（兑现前的静止除外）：读字的停留里镜头保持缓推或漂移，不只靠换字幕撑着。解说片可以为读字停得更久。
- 文字停留 ≥ 字数 ÷ 4.5 + 1.5 秒，短视频 ≥ 字数 ÷ 4.5 + 0.8 秒（英文按字母数 ÷ 15）；不够就删字或并拍，不压缩停留。数字、金额、百分比、产品名各算 1 字；同时出现的一组标签合起来算；计数器按落定后的数值算。和"随旁白出现"冲突时保停留：字留到读完，下一个元素错开位置出现。字幕不受这条约束，它跟着旁白走。
- 兑现之前主体与镜头都静止 `hold` 秒，颗粒和镜头推进也停（模板的 `Film.tsx` 已经接好，`fish_tts.py` 自动在兑现句前留出这段停顿）。上一拍的字在静止段开始前读完退场，或者留下来成为兑现画面的一部分。
- 兑现拍从兑现那个动作开始（落下、点亮、合拢），0.3 秒内落定，冲击音对准落定那一帧，赶在旁白开口前；说明文字随后跟着旁白出现。结局状态在尺寸、颜色和出场冲击上都压过前面的问题状态（"通过"比"打回"大、用全片独有的颜色）；缩到四分之一看，第一眼看到的是结局。
- 最后 2 秒是结果画面：主角做完开头许诺的那个动作，主体完整不出画，有一行结论字；只看末帧也说得出结论。

完成：旁白文稿过了上面几条；`timeline.json` 和节拍表写好；节拍表对照 [反 PPT 清单](anti-ppt.md) 没有命中项。

## 4. 视觉开发

先定外观再写动画代码；跳过这步直接写动画，是成片平庸的头号原因。

1. 代码动画路线（包括用了生成零件的）先按 [解说语法](grammar.md) 给每段旁白选语法；生成素材路线的动法由风格家族定。项目已有品牌画风（角色、插画、配色）时不比风格，按品牌出一张代表静帧直接进陌生人测试；否则挑 2–3 个风格（生成素材路线从 [生成素材](generated.md) 的风格家族里挑；用户已指定风格时，比同一风格下的 2–3 套配色或构图），各出一张代表静帧并排比较：生成素材路线用 gpt-image skill 生成最重要的那个零件（或它和背景的拼合），选中的那张直接作后续零件的 `--ref`；代码路线让 `Scene` 读 `getInputProps().look` 切换色板和字体，用 `npx remotion still Main out/look-a.png --frame=<帧号> --props='{"look":"a"}'` 各渲一张，选定后删掉切换代码。
2. 陌生人测试：给静帧（不给旁白、方向和 `LOOK.md`）派一个无上下文的子代理，没有派子代理的工具时起一个无历史、不加载 skill 和项目上下文的命令行会话（如 `pi -p --no-session --no-skills --no-extensions --no-context-files`，图片用 `@路径` 传入，并限定它回复的行数），让它说出画面上每个东西是什么、这部片子在讲什么。说错或说不出就改，改到说得出再给用户挑。风格静帧过一次即可，之后的画面交给第 7 步的审片。
3. 画面写出第一版后，先用 `npx remotion still` 渲 3–6 个关键时刻全尺寸看构图（焦点、留白、字和图的关系），构图定了再细调动画。

完成：选定风格的色板、字体、材质、有意的特征（如步进、套色错位）和禁用项写进项目根的 `LOOK.md`；风格静帧过了陌生人测试，关键时刻的静帧过了 look.md 的检查。

## 5. 实现

| 路线 | 适用 | 做法 |
|---|---|---|
| A · 代码动画 | 数据、产品演示、几何系统、概念讲解 | Remotion 模板，读 [Remotion](remotion.md) |
| B · 生成素材 | 人物、历史、文化、故事、品牌，以及像素、黏土、动画等插画风格 | gpt-image 出背景和零件、Remotion 驱动，另读 [生成素材](generated.md) |
| C · 模型直出 | 用户点名要实拍质感 | 读 [模型生成](model-generation.md) |

- 写动画前读 [运动](motion.md)，时序数值和镜头规则以它为准。
- 画面里出现具体物件（人物、器官、设备、文物、动植物）时，代码路线也用 gpt-image 生成透明底零件，做法见 [生成素材](generated.md) 的零件一节；代码负责图表、数据、连线、文字和运动，代码画的物件只限几何图形和图标。
- 用户要字幕时把 `timeline.json` 的 `captions` 设为 true，模板的 `Captions` 按旁白原文切短句、贴安全区下沿显示；颜色按 `LOOK.md` 改它的 `ink`、`stroke`、`plate`。
- 产品画面用真实截图或录屏，不用代码重建界面（重建出来像网页模型）。现有截图在成片里糊，就按成片尺寸重新截：浏览器按目标宽度和 2 倍像素截，终端按竖版宽度放大字号重录（如 VHS）。只讲一两行时，裁出那一块放大，不把整页缩小塞进画面。光标和点击要画出来，让每个界面反应都有可见的起因。演示里的数字不编，用相对条形或骨架线。

用户在场时，先做 10–15 秒样片（钩子加一个中段，带真旁白和粗配乐），静音过一遍陌生人测试（抽帧也行），再给用户确认，然后做全片。用户不在场时不做样片，直接渲全片，抽帧对照 [反 PPT 清单](anti-ppt.md) 自审。

完成：用户在场时样片已确认；全片草稿已渲染。

画面时间锁定后按 [声音](sound.md) 剪定配乐、补音效、调混音。

完成：sound.md 的每一节都已做过；有配乐时另渲染一版无配乐版本（只去掉配乐，保留旁白和音效）。

## 7. 检查与审片

以下命令都在项目目录运行。

1. `npm run layout`（查哪几项见 `scripts/layout.mjs` 开头）：镜头停住时报的问题必须修，`transient` 里不到 0.5 秒的可以留。以文字为主的画面（清单、片尾行动屏）把容器标 `data-card`，不量主体。代码画的主体、图片之间和图片压字的遮挡量不到，靠审片。
2. `npm run render` 全尺寸终渲到 `out/render.mp4`，然后 `python3 scripts/media.py master out/render.mp4 --out out/v1.mp4`。版本号递增（`--out` 已存在时 master 会拒绝）；无配乐版同样 master 成 `out/v1-nomusic.mp4`。
3. `python3 scripts/media.py check out/v1.mp4 --timeline timeline.json`（判定和列出的段落见 `scripts/media.py` 开头），审片图在 `out/v1-review/`。列出的段落这样处理：
   - `same_shot`（构图超过 `shot` 秒没变）和 `long_stills`（整帧静止超过 `still` 秒）：短视频每段都改；解说片说得出理由（读字、点题镜、必须同屏的对比）的可以留。静止在缩到 160×90 的画面上判，细线、小物体的移动测不出，逐帧确认在动的不用改；背景不变、只有零件进出的同一机位 `same_shot` 测不出，审片仍要看。
   - `cuts`：对照节拍表里写了硬切的位置，计划外的硬切是跳帧或元素突然换掉。
4. 看审片图：
   - `sheet.png`（每拍首尾各一帧，长拍加中间一帧）：不读字幕也要看出连续推进，不是一组幻灯片缩略图。
   - `first.png`：全尺寸看封面；sheet 上可疑的帧，用同一时间点抽全尺寸帧再看。
   - `seam-*.png`（节拍边界前后的逐帧条带）：找出 carry 元素，同一个元素在边界两侧都在、位置或大小变了；认不出就是替换。再按死停、两个动作接力、单帧闪、交叉淡化逐条查。
   - `phone.png`（每秒一帧、360px 宽）：主信息在这个尺寸下仍要读得出。
