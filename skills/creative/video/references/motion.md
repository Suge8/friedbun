# 运动

## 时序数值

起点值，看帧后再调；偏离时要说得出理由。时间用模板 `src/motion.ts` 的 `useTime()` 取，多关键帧、分段缓动和镜头缩放用 `tween`、`zoom`。

- 入场用 ease-out，退场用 ease-in；退场时长约为入场的 65–75%。全片定一条入场缓动、一条退场缓动（模板的 `OUT`、`IN`）。
- [解说语法](grammar.md) 和生成素材的风格家族各自定了运动密度和缓动，与下面的起点值冲突时以它们为准。
- 12fps 步进只给纸拼贴、印刷、像素这类手工感风格里的纸片、贴纸、角色，镜头和数据图形（点、线、条）照常平滑；其余风格和代码动画的元素、镜头都用平滑时间，步进的光波、曲线、数据条读作掉帧。
- 入场 0.24–0.38 秒：透明度加 10–28px 位移，不只用透明度；缩放入场从 0.90–0.97 起，不从 0 起。元素按 12fps 步进时，大物件入场至少 0.5 秒，否则只有三四步，读作闪现。
- 父子元素不同时起停，子元素晚 50–150ms；错开间隔要明显短于动画本身，小于 20ms 就合成一个动画。
- 匀速只给机械运动；批量入场越来越快，收尾停 0.5 秒。
- 动作落定后停 100–200ms 再开始下一个动作。
- 计数器不过冲，不做卡通弹跳。
- 同一主体上两个前后接力的动作读作故障，合并成一个手势。
- 每个动作能说出"因为……"，说不出就删。

## 镜头

- 每镜一个镜头动作：缓推、横移、视差平移三选一，点题镜不动；相邻镜头动作要变，换景别（中远景切到近景特写）也算变。
- 推拉配一点横向或旋转分量，不只缩放；整体推进和元素自身的缩放不放在同一层（外层推，内层动）。
- 镜头推近会把画面边缘的文字往外推，拉远会把文字缩小：要读的标题、说明放在镜头外层，不随镜头缩放；只有地名、印章、招牌、贴着某个物体的标签这类画在物体上的字放进世界里：推到最近不出安全区，拉到最远不小于最小字号。镜头大幅横移前，外层的标题先退场，不让场景从字底下滑过。边拉远边移动时，镜头中心的 x、y 和缩放用同一组关键帧时刻，主体才留在画面里。
- 切点放在运动最快处，两侧方向和速度一致。整屏随节拍冲击全片最多 3 处，默认只动元素层。
- 全帧率下单帧位移过大（1920 宽超过约 80px）会频闪成重影：降速、改步进，或只给 1–3 个急速动作加运动模糊；要读的字不模糊。
