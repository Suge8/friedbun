# 反 PPT 闸门

命中任一条，先改运动方案再写代码或渲染。

## PPT 失败模式

- 方案是一页页幻灯片的列表；多数节拍是居中标题 + 三条要点 + 淡入
- 素色背景上的大卡片，周围没有世界；同一卡片布局反复出现，没有有意义的运动变化
- 物体出现后不变形、不行进；图片、图标、组件入场后静止
- 场景切换重置全部视觉上下文，节拍之间没有连续视觉系统
- 后一拍替换前一拍：边界上没有存活并继续运动的元素。每拍内部再动也是幻灯片
- 整页缩成小卡片展示，页面里的动作在卡片尺寸下看不出
- 画面始终在动，没有 ≥1 秒的静止停顿；有停顿，爆发才有分量
- 转场与叙事隐喻无关；每个元素用同一淡入缓动
- 没有镜头、遮罩、路径、揭示、形变或系统级运动
- 文字承载全部想法，视觉只是配图
- 关键帧像互不相关的海报；重要物体过小、过暗或被效果遮挡

目标：一个连续视觉系统贯穿全片；每个节拍有主要运动物体和状态变化；转场由隐喻驱动；不读字幕也能从 contact sheet 看出推进。

## 成片检查

渲染后按序跑，任一条不过就改片再渲。连续性与静止两条的思路来自 feitangyuan/onetake（PolyForm Noncommercial，只借思路，未复制其文本或代码）。

- **连续性**：每个节拍边界抽前后 0.3 秒与边界共三帧，指认存活元素：同一个元素在两侧都在，位置或大小变了。指认不出就是替换，按节拍图的 `carry` 改。把承接做成一个元素的变化（同一图层缩放、形变），不要两个元素交叉淡化：检查和观众都认不出后者是承接。硬切只在节拍图声明过的三种位置。
- **静止**：`ffmpeg -hide_banner -i out/x.mp4 -vf freezedetect=n=-50dB:d=1 -an -f null - 2>&1 | grep freeze_duration`，至少一行；没有输出说明处处在动。`n=-50dB` 容得下纸纹噪点跳动。
- **音频**：`ffmpeg -hide_banner -i out/x.mp4 -af volumedetect -vn -f null - 2>&1 | grep max_volume`，不高于 -3 dB（AAC 编码会再冲高）。
- **参考视频**（有参考时）：`-vf freezedetect=n=-50dB:d=0.5,scdet=t=10:s=1` 得到静止段与硬切时间，记下静止占比、硬切数、镜头时长范围。

## 反 AI 味

以下组合已等同于「AI 生成的科技演示」，用户没点名就不用：

- 黑底 + 发光球体/发光节点
- 粒子星尘、飘浮光点
- 网络连线图当主视觉（节点+边+脉冲）
- 轨道环绕的图标
- 紫青渐变霓虹辉光
- 处处 60fps 丝滑缓动（编辑感来自步进与粗糙，见 editorial-collage.md）

替代方向：纸张/暖白底、照片抠图、真实截图与档案素材、手绘批注、印刷质感、步进运动。

## 排版

视频一眼看懂整帧，不是读密集 UI；画面停留不到一秒也要读懂。违反即打回。

- 每个场景一个焦点，围绕它构图；可读元素不与主运动物体争同一区域。一条主信息 + 一个支撑视觉 + 一两个背景强调；卡片、徽章、边框、胶囊、小标签是 Web UI 模式，会让画面杂乱。
- 1080 宽合成的最小字号：主标题 84px、重要支撑文字 44px、标签 32px，其他宽度等比放大（1920 宽主标题 ≥150px）；拿不准就放大。小字视为装饰。行短，长想法拆成多个场景，不缩字号。
- 安全区（1080 宽）：关键文本离左右 ≥80px、离上下 ≥100px；字幕底部边距 ≥5%，不压在运动路径上。
- 可读内容放 `flex`/`grid` 容器，用 `gap` 排布，不各自用 `top`/`left` 手动定位；绝对定位只给垫在内容后面的背景、装饰、光效、粒子。每个主要元素预留一个槽位，动画只用 `opacity`/`transform`/`scale`，不占别的元素的空间；从屏外进入的元素，终点也属于它的槽位。
- 文字长度未知时按会换行设计；文字与背景强对比，难读时加淡背景形状；同一区域不堆多块文字。
- 拥挤用时间解决：功能逐个展示，或删一个元素、放大焦点、把次要元素移到另一场景。
