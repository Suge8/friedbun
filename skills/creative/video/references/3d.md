# 3D 渲染

用 three.js 在 Remotion 里逐帧渲染真 3D：有影棚灯光、柔和阴影、金属、玻璃、黏土这类材质，质感是平面插画给不了的。时间表、字幕、声音、检查流程都和模板一样，只是画面换成一块 3D 画布。

适合产品主视觉、logo 片头片尾、用一个抽象物件讲概念、题材本身要材质感的片子。大量文字、真实界面截图、人物表演不用它：前两种走代码动画路线，人物走生成素材路线。

## 起步

- 在模板项目里装 `npx remotion add @remotion/three`（版本和模板对齐），再装它的同伴 `three`、`@react-three/fiber`；要环境光、贴地阴影、圆角体这类现成件时加 `@react-three/drei`。版本按 `@remotion/three` 的 peerDependencies 取当前版。
- 画面放进 `Scene` 里的 `<ThreeCanvas width height>`。所有运动从 `useTime()` 或 `useCurrentFrame()` 算，不用 R3F 的 `useFrame`；渲染时它会把 `frameloop` 设成 `never`，靠 Remotion 逐帧推进。随机数用 `random(seed)`。
- three.js 要靠 ANGLE 渲染器才能在无头浏览器里跑：模板的 `remotion.config.ts`（渲染命令）和 `scripts/layout.mjs`（排版检查）都已设好。
- 标题、状态牌、字幕放在画布上面的普通 HTML 层，不做 3D 字：字清楚，`npm run layout` 也量得到。只有 logo 这类本身就是物件的字才做成 3D。

## 影棚起步配方

数值是起点，渲静帧看过再调。

- 无缝影棚：只设背景色，不放地面平面（同色地面也会露出一条地平线），物件下方只放贴地阴影（drei 的 `ContactShadows`），物件才"落"在地上。
- 一盏大面积主光在上前方，一盏轮廓光在后侧，轮廓光可以用品牌强调色；环境光用低强度的室内环境（drei 的 `Environment` 或 three 的 `RoomEnvironment`），给金属和玻璃反射。
- 材质用 `MeshPhysicalMaterial`：金属 metalness 1、roughness 0.05–0.2；黏土、磨砂塑料 roughness 0.6–0.85；玻璃 transmission 1，配 thickness 和 ior 1.45。
- 镜头视场角 30–40°（接近 50mm 镜头），一镜一个镜头动作，推拉用最软的缓动（ease-in-out），物件用更利落的缓动。
- 后期克制：辉光只给画面里最亮的那一处，暗角 5–8%，颗粒 1–2% 按帧号播种；不加镜头光晕。
- 急速动作的运动模糊用 `@remotion/motion-blur` 的 `<CameraMotionBlur>`，只包住那几秒，样本数 5–10。

## 做和改

- 先把 3–4 个关键帧用一条命令渲出来（写法见 [Remotion](remotion.md)），定下灯光、材质和构图，再写动画。简单场景几百帧十几秒就渲完；后期和运动模糊会慢下来。
- 几层透明物体叠在一起（杯子、水、冰）：从外到内给 `renderOrder`，水和玻璃关掉 `depthWrite`，冰这类要看见内部的用 transmission；否则会互相吞掉或闪。
- 大量同样的小物件（分子、粒子）用 `InstancedMesh`，每帧按时间算出每个实例的位置写进矩阵，不逐个建网格。
- 贴在 3D 物件旁边的标签：用相机把物件的世界坐标投影成屏幕坐标，再把 HTML 标签摆过去（或用 drei 的 `Html`），字仍在 HTML 层，layout 量得到。
- 检查与审片照导演流程第 7 步走；`layout` 只量得到 HTML 层的字和图片零件，3D 主体的大小和遮挡靠审片。
