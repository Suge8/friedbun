# 生成素材路线

用 gpt-image skill 画背景和零件，Remotion 负责组装、镜头和运动，不经过视频模型：文字始终清晰，可以反复重渲，成本接近零。风格不预设，从下面的家族里选，或按 [外观](look.md) 的旋钮自定。代码动画路线里出现具体物件时，也按这里的零件做法生成。这条路线里抽象概念（审查、协作、记忆、并行）也画成有质感的物件或场景，不用代码画的几何块代替；代码只画数据、连线和文字。

素材的样子在生图时就定了，动效救不回来；风格不同，怎么动也不同。

## 风格家族

| 家族 | 适合 | 风格块关键词 | 怎么动 |
|---|---|---|---|
| 纸拼贴、印刷 | 历史、人文、新闻 | hand-cut paper collage, torn edges, halftone print, risograph, letterpress | 元素 12fps 步进、镜头平滑；纸片拍上、飘落、批注逐笔描出，硬投影；纸是平的，不做 3D 旋转 |
| 现代扁平插画 | 科普、产品、商业 | modern flat vector illustration, bold geometric shapes, limited palette, generous negative space | 平滑缓动；形状变形、遮罩揭示、镜头推拉 |
| 黏土、可爱 3D | 儿童、生活、轻松的品牌 | cute 3D claymation, rounded chunky shapes, pastel palette, soft studio light | 平滑；落地先压扁 10–15% 再回弹，弹簧可带一点过冲；`Part` 用柔和投影；角色拆成身体、头、手臂零件，绕关节转着做动作 |
| 动画背景 | 情绪、故事、旅行，也适合要氛围的科普 | hand-painted anime background, cel-shaded, cinematic sky | 镜头慢推加多层视差，光影和天空跟着动；讲情绪时主体少动，讲变化时主体照常动 |
| 像素 | 游戏、编程、科技怀旧 | 16-bit pixel art, limited palette, crisp pixel grid, no anti-aliasing | 位置取整到像素格，元素 8–12fps 逐帧；`Part` 设 `pixelated`，放大动作用整数倍；硬切或像素化溶解。中文像素字体用 Fusion Pixel Font（SIL OFL） |
| 玻璃、发布会 | 科技产品、AI | frosted glass, soft gradients, clean 3D render, keynote aesthetic | 平滑偏慢，轻回弹（bounce ≤0.15），从模糊里浮出；不加发光球和霓虹（外观的禁用清单） |
| 瑞士几何 | 观点、数据、设计 | Swiss international style, strict grid, bold flat color blocks | 色块沿网格滑入、硬切，几乎不用缓动 |

## 写 prompt

```
[风格块，全片每张图开头都相同] <家族关键词>, <LOOK.md 的地色和墨色，写具体颜色，不写强调色>, <质感>. NOT photo, NOT stock 3D.
[内容] 场景：SCENE as distinct layers: {主体}, {道具}, {背景物件}; clear edges.
       零件：A single {物体}.
[背景] 整幅背景写 one flat {色名} background；要单独动、或要叠在别的东西前后的物件都是零件，不写背景，加 --transparent
[画幅] straight-on framing, even light, {16:9 或 9:16}
```

- 以正向描述为主，实际出过的具体瑕疵才在末尾用一行点名避开。描述物件用 object，不用 figure：后者常被画成人形。
- 强调色只写进承担它的那个零件的内容行，风格块和其余零件的 prompt 里都不提这个颜色。
- 背景和零件里画同一种东西（六边形、窗格、轨道）时，两边 prompt 写同一个朝向和比例。
- 文字不画进图，后期在 Remotion 里叠；出现假字就重生成。
- gpt-image 最大约 1672×941，比 1920×1080 的成片小：整幅背景不做大幅推近，要推近看的地方单独生成成零件。背景要放大到盖满画面，再按镜头走得最远、拉得最远的那一帧留出余量，镜头的 x、y、z 不超出这个范围，否则边缘露出底色。镜头要横移很远时，背景生成一张够宽的长卷（prompt 写 wide panoramic），不平铺拼接。

## 零件

1. 先按导演流程第 4 步比完风格，再按选定的风格块生成零件；最多同时生成 3 张，过载、限流和断连时脚本会自己等一会儿重试两次。
2. 先生成最重要的一个零件，确认风格对了，之后的同类零件都带上 `--ref <它的路径>`，质感和笔触才一致；参考图里的东西会被画进新图，所以背景和别的物件（猫的参考图配纸箱）不带它，靠同一段风格块统一；同一角色的每个姿势都带它自己的第一张图作 `--ref`，比例、毛色、五官不能变。两个角色同框时用颜色或配饰区分，画风相同。每个要单独动的东西生成一张透明底 PNG：风格块加一句物体描述，加 `--transparent`；投影在 Remotion 里加。人物要做动作时，把会动的部分（手臂、递出去的东西）单独生成，和身体分开摆。钻进、躲在后面这类前后遮挡，把挡在前面的部分（箱子前壁、门框）单独生成成零件，摆在角色上层。整体换姿势（弓背变坐下、站着变跳起）时每个姿势各生成一张，在动作最快或压扁最低的那一帧直接换图，不拿一张图形变出另一个姿势。
3. `python3 scripts/media.py trim public/parts/*.png` 裁掉透明边距，`Part` 才按物体本身居中。
4. 把所有零件叠在片子的底色上拼成一张图看一遍：底没去干净、带光晕、质感和别的零件不一样、画错了物件的，重新生成，不手工抠、不后期补救。

## 组装和运动

- 模板 `src/stage.tsx`：`Camera` 是镜头，`Part` 摆零件（投影、关节、像素渲染可调），`Strip` 是文字条（撕边纸条或规整色块），`Grain` 是逐 3 帧换相位的颗粒。项目需要的其他组件建一次，各镜复用。
- 静图要用裁切、遮罩、视差、揭示或形变动起来；静图加文字不算视频。
- 纸拼贴的细节：硬投影偏移 2–6px、模糊 0–1px；套印错位按固定种子偏移，不做动画；两种深色饱和墨 multiply 叠在一起会成黑泥，叠色时至少一种用浅色；想要墨印进纸的质感，在浅色纸底上给零件加 `mix-blend-mode: multiply`。
- 英雄元素（纸鸟横穿全屏之类）只在关键拍出现一次。

## Seedance 补镜

只有某一镜需要真正的有机动作（人做动作、动物动）时才用，参数见 [模型生成](model-generation.md)。

- 单镜动作：`--first-frame` 用已确认的静帧；运动 prompt 写一个镜头动作、图层视差、保持原风格的质感、情绪、色板，幅度写 subtle，文字区留空。
- 组装镜头：首帧是与尾帧同底色的空画面（ffmpeg 生成纯色图），尾帧是确认过的完成静帧，prompt 写明 Image 1 是精确的空白首帧、Image 2 是精确的完成尾帧，动作是从空到满的组装。
- 检查时看组装过程和最终落位，不只看尾帧。
